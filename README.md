# LensBench

本地镜头几何工作台。运行 `python3 app.py` 后访问端口18921，或运行 `docker compose up --build`。数据保存在 `LENSBENCH_DATA_DIR`，容器默认使用独立命名卷；可下载完整工程ZIP并导入为新工程。

主流程：创建工程或打开明确标为合成的六张棋盘演示；设置内角点列/行和已知格边毫米；导入照片，检测角点，选择纳入照片，计算普通针孔镜头档案；查看固定来源的重投影误差和畸变位移；使用档案生成去畸变照片及有效遮罩、棋盘姿态轴或棋盘平面展开。工程支持多个固定档案、外部档案JSON导入与选择、快照恢复和完整ZIP往返。

双目立体流程：在工程内选择同一时刻拍摄的左右原图与各自镜头档案，录入左→右旋转（矩阵或旋转向量）和平移（毫米），计算并保存立体结果。查看器支持校正核对（水平极线与右图对应点）、深度图与单点毫米距离/原始左系坐标、有效区域与逐点无效原因（弱纹理、重复条纹多候选、遮挡不一致、校正区外、视差超范围），拿不准的对应一律留空，不做填洞或平滑猜测。重复条纹处可查看多个说得通的候选视差，确认少量对应点并圈选所属连续表面后重新消歧：确认只作用于与确认点连通且候选相近的区域，不会跨过前景边缘改到别的物体；互相矛盾的确认会被标出且不应用。每次结果固定原图、几何关系、人工确认与有效性依据，之后改镜头档案或重算不改变旧结果；浮点深度（NaN无效）、无效遮罩与原始左相机坐标系毫米点云PLY均从同一次确认导出，无效点不进入点云。

坐标是EXIF转正后的图像左上原点像素；镜头档案严格绑定宽高，不自动对缩放图片套用内参。棋盘物点以第一内角为原点，列方向X、行方向Y，长度毫米。普通标定不自动判断可观测性或剔除异常观测，RMS低也不等于标定可靠；应覆盖不同倾角、距离和画面位置。演示透视图片仅为流程体验，不是精度验证。平面展开只适用于棋盘平面，不对离面物体测距。每工程40幅照片，每幅24MB、32–4096边长且最多1200万像素；工程ZIP96MB、展开256MB。双目两图需宽高一致；多相机联合标定仍未提供，立体结果不反向更新镜头档案。

图像准备入口 `/prepare` 提供已有照片导入、旋转裁切、颜色/曝光、遮罩、图像配准、融合、频谱及导出工具。`image_lab/`、`static/app.js`、`static/style.css`、`templates/prepare.html` 是自有早期产品solo_20中准备子系统的字节复用；其源头由solo_19及更早准备产品继承，LensBench主业务 `lensbench/`、镜头页面和样图生成全部为本项目新建。保留准备子系统是为了原始照片处理与几何工作流衔接，不把旧显微业务带入本产品。
