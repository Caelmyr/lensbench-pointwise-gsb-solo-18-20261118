# LensBench

本地镜头几何工作台。运行 `python3 app.py` 后访问端口18921，或运行 `docker compose up --build`。数据保存在 `LENSBENCH_DATA_DIR`，容器默认使用独立命名卷；可下载完整工程ZIP并导入为新工程。

主流程：创建工程或打开明确标为合成的六张棋盘演示；设置内角点列/行和已知格边毫米；导入照片，检测角点，选择纳入照片，计算普通针孔镜头档案；查看固定来源的重投影误差和畸变位移；使用档案生成去畸变照片及有效遮罩、棋盘姿态轴或棋盘平面展开。工程支持多个固定档案、外部档案JSON导入与选择、快照恢复和完整ZIP往返。

坐标是EXIF转正后的图像左上原点像素；镜头档案严格绑定宽高，不自动对缩放图片套用内参。棋盘物点以第一内角为原点，列方向X、行方向Y，长度毫米。普通标定不自动判断可观测性或剔除异常观测，RMS低也不等于标定可靠；应覆盖不同倾角、距离和画面位置。演示透视图片仅为流程体验，不是精度验证。平面展开只适用于棋盘平面，不对离面物体测距。每工程40幅照片，每幅24MB、32–4096边长且最多1200万像素；工程ZIP96MB、展开256MB。当前没有立体深度或多相机联合标定。

图像准备入口 `/prepare` 提供已有照片导入、旋转裁切、颜色/曝光、遮罩、图像配准、融合、频谱及导出工具。`image_lab/`、`static/app.js`、`static/style.css`、`templates/prepare.html` 是自有早期产品solo_20中准备子系统的字节复用；其源头由solo_19及更早准备产品继承，LensBench主业务 `lensbench/`、镜头页面和样图生成全部为本项目新建。保留准备子系统是为了原始照片处理与几何工作流衔接，不把旧显微业务带入本产品。
